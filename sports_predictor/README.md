# Sports Predictor

This is a simple Flask web application for predicting the outcome of a match between two teams. The prediction is generated randomly for demonstration purposes.

## Requirements

- Python 3
- Flask

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Running the Application

```bash
python app.py
```

Visit `http://127.0.0.1:5000` in your browser.

## Running Tests

```bash
python -m pytest -q
```
